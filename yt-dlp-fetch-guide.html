0. 先进仓库目录

  1. 按 Win + X → Windows PowerShell（推荐用 PowerShell，不用 CMD，否则 % 转义不同）
  2. 执行：
cd D:\notebook\BrotatoStratGuide yt-dlp --version

有版本号即装好。若提示找不到，先 winget install yt-dlp 再重开 PowerShell。

1. 贴回日期（三行，复制输出给我）

PowerShell 里逐条跑，--skip-download 只取元数据不下视频：

yt-dlp --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=Wge0_hd9Rt8" yt-dlp --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=QbKT2VHnqbc" yt-dlp --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=dhQ67IeBq0Q"
你这张截图就是缺 JS 运行时 + 被风控：No supported JavaScript runtime 后面跟 Sign in to confirm you're not a bot。先装 Node 再重跑，八成直接过。NA | NA 才是列表页正常。

0b. 装 JS 运行时（只装一次）

  1. PowerShell 里跑：winget install OpenJS.NodeJS，装完关掉重开 PowerShell
  2. 验：node --version 有版本号就行（装 Deno 也行，但 Node 最稳）
  3. 回同一目录重跑第1步三条，警告里的 EJS 链接消失即生效
winget install OpenJS.NodeJS node --version

0c. 登录态（还报 Sign in 才看，二选一）

原理：YouTube 把机房/无登录匿名请求拦了，读你本地浏览器已登录的 cookies 只为过验证，不上传密码，关掉浏览器是怕文件被锁。
  1. 确认浏览器已登录 YouTube（能正常看片就行），然后先关掉该浏览器再跑命令
  2. Chrome 用户直接跑下面三行；Edge 把 chrome 全换 edge，Firefox 换 firefox
  3. 成功标志：红字 Sign in... 消失，出 标题 | 202xxxxx | 时长 三段
yt-dlp --cookies-from-browser chrome --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=Wge0_hd9Rt8" yt-dlp --cookies-from-browser chrome --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=QbKT2VHnqbc" yt-dlp --cookies-from-browser chrome --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=dhQ67IeBq0Q"

隐私：只读本地 cookies 数据库过验证，不读密码不上传；实在不想给浏览器，就换网/等10分钟再试无 cookies 版。

报 Failed to decrypt with DPAPI（10927） 就是新版 Chrome 应用级加密锁死，--cookies-from-browser chrome/edge 全灭不用试了，直接走扩展导出（浏览器自己解密，最稳）：
① Chrome 商店装 Get cookies.txt LOCALLY；② 打开 youtube.com（确认已登录）→ 点扩展 → 只导出 youtube.com → 存为仓库根 cookies.txt（已进 .gitignore，不会入库）；③ 跑下面 --cookies cookies.txt 版（不用关浏览器）：
taskkill /F /IM chrome.exe yt-dlp --cookies-from-browser chrome --print "%(title)s | %(upload_date)s" --skip-download "https://www.youtube.com/watch?v=Wge0_hd9Rt8" yt-dlp --cookies cookies.txt --print "%(title)s | %(upload_date)s | %(duration_string)s" --skip-download "https://www.youtube.com/watch?v=Wge0_hd9Rt8" yt-dlp --cookies cookies.txt --write-auto-sub --sub-langs en-orig --sub-format vtt --skip-download -o "data/subs/engineer__ultimate.en-orig.vtt" "https://www.youtube.com/watch?v=Wge0_hd9Rt8"
