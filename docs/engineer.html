开局 / 中期 / 后期

开局（W1-5）

（W1-5）锁 1 把扳手升 tier，只 roll 收获 (Harvesting) / 工程 (Engineering)；站炮塔群中间吃收入，结构件先占 1-2 个，前半段靠扳手自己清。 出处：备选视频 chapters 早中晚分段与全程打法。
买什么：扳手 (Wrench) → 占 6 把，和平蜜蜂过渡收获

中期（W6-12）

（W6-12）转向点：结构数量铺起来吃灯塔 tempo 红利，击退撑起安全壳；工程一件也别多直购，全靠扳手 tier 与新结构。 出处：备选视频 chapters 早中晚分段与全程打法。
买什么：补炮塔 + 灯塔 tempo，追护甲与回复

后期（W13-20）

（W13-20）转向点：最大生命 (Max HP) + 护甲补坦度，乘区只认改良工具与时钟；绝不离巢乱跑，离巢即暴毙，拉怪穿炮塔群。 出处：备选视频 chapters 早中晚分段与全程打法。
买什么：T4 扳手 + 改良工具，堆血甲站住

升级优先级

属性 Top3：收获 (Harvesting) / 工程 (Engineering) / 护甲 (Armor)；生命窃取与暴击出了也不拿；血量告急时保命优先。（两层：先 Top3 再点名） 出处：全程 roll 牌与视频描述。

商店优先级

属性 Top3：工程 (Engineering) / 攻击速度 (Attack Speed) / 最大生命 (Max HP)；必拿：炮塔 / 改良工具 / 和平蜜蜂；必刷：缺关键结构时点 1-2 次重随；工程直购永远只补少量。（两层：先 Top3 再点名，升级在前） 出处：全程商店与视频描述。

避坑

  • 别离巢乱跑：工程伤害慢，只能站炮塔群里慢慢磨，跑出去即被弹幕逼死。
  • 别直买工程堆数值：线性堆工程不如多买一座结构，防御与数量才是输出。
  • 别碰生命窃取 (Life Steal) / 暴击：作者明确不好用，拿了等于白板。

高难特例

高难特例：仅 Nightmare / Ultimate 成立——环境弹幕逼走位，贴边开局让怪同向来；W16 增强苍蝇与精英逼离巢，提前拉怪穿炮塔群，击退配燃烧炮塔造壳。

开局 / 中期 / 后期

开局（W1-5）

（W1-5）只买扳手凑数量，站炮塔群中间，roll 工程 (Engineering) / 收获 (Harvesting) / 幸运 (Luck)，拿护甲过渡，不管元素/射程/暴击。

中期（W6-12）

（W6-12）转折点：炮塔落位+经济/防御成型，补护甲和血量，精英靠炮塔集火+走位蹭，40% 经验可拿，省钱别乱 reroll。
买什么：工程/收获/护甲，追炮塔数量

后期（W13-20）

（W13-20）转折点：血量+回血硬抗，Wave 19 提前站定摆炮塔阵，最终 boss 靠炮塔数量+回血磨，全程回血不用嗑药流。
买什么：T4 扳手 + 炮塔拉满，回血站撸
