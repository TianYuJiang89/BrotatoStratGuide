机制一句话

远程养炮塔：远程伤害 (Ranged Damage) 吃 200% 加成，波次过半时 100% 远程按 1:2 暂转化为工程 (Engineering)；工程直购 -75%、近战 (Melee Damage) / 元素 (Elemental Damage) -100%，全靠转化养结构。解锁条件：10 远程伤害 (Ranged Damage) + 3 结构；胜场奖励：改良工具 (Improved Tools)。（机制译自 Wiki，中文待客户端校对；数值演示占位，选片后按视频口径替换）

开局 / 中期 / 后期

开局（W1-5）

（W1-5）锁 1 把 T1 枪升满，只拿远程伤害 (Ranged Damage) / 攻击速度 (Attack Speed)；结构件便宜先占 1-2 个，前半段靠枪自己清。
买什么：冲锋枪 (SMG) → 升满

中期（W6-12）

（W6-12）转向点：结构数量铺起来吃转化红利，过半后 1 远程 = 2 工程；工程 (Engineering) 一件也别直购，全靠转化。
买什么：补第 2 把枪 + 炮塔 / 地雷

后期（W13-20）

（W13-20）转向点：最大生命 (Max HP) + 护甲补坦度；近战 / 元素一件不拿，站位让炮塔吃波次。
买什么：T1 升满后追攻击速度与血量

升级优先级

远程伤害 (Ranged Damage) > 攻击速度 (Attack Speed) > 最大生命 (Max HP)；工程 / 近战 / 元素出了也不拿；血量告急时保命优先。（演示口径，选片后替换）

商店优先级

属性 Top3：远程伤害 (Ranged Damage) / 攻击速度 (Attack Speed) / 最大生命 (Max HP)；必拿：炮塔 / 改良工具；必刷：缺关键结构时点 1-2 次重随；工程直购永远跳过。（演示口径，选片后替换）

避坑

  • 别直买工程 (Engineering)：-75%，全靠波次过半转化。
  • 别碰近战 (Melee Damage) / 元素 (Elemental Damage)：-100%，拿了等于白板。
